# myfreelab.ru — лаборатория Алексея Ан

Сайт-витрина: лендинги, квизы, калькуляторы, чат-боты и трекеры для малого бизнеса. Каждый кейс на витрине — работающий проект, его можно открыть и попробовать.

Живой сайт: https://myfreelab.ru

Одностраничное приложение на React 19 + Vite 5. Русская и английская версии, язык выбирается по браузеру и переключается в шапке. Весь контент лежит в двух JSON-файлах, код менять не нужно.

## Где что менять

| Что | Файл |
|---|---|
| Кейсы | `src/content/projects.json` |
| Тексты RU/EN, пакеты и цены, FAQ, контакты, адрес приёмника заявок | `src/content/site.json` |
| Цвета, шрифты, сетки | `src/styles.css` |
| Обложки кейсов, фото | `public/images/` |
| Заголовок, описание и превью для поиска и мессенджеров | `index.html`, `public/og.png` |
| Политика обработки данных | `public/privacy.html` |

### Как добавить кейс

Добавьте объект в `projects.json`:

```json
{
  "id": "coffee-shop",
  "group": "leads",
  "url": "https://coffee.myfreelab.ru",
  "image": "/images/coffee-shop.webp",
  "color": "#2A1E17",
  "watermark": "Кофе",
  "stack": ["HTML", "CSS", "JavaScript"],
  "ru": { "kicker": "Лендинг", "title": "Кофейня", "lead": "…", "task": "…", "solution": "…", "result": "…" },
  "en": { "kicker": "Landing page", "title": "Coffee shop", "lead": "…", "task": "…", "solution": "…", "result": "…" }
}
```

- `group` — направление на витрине: `leads` (привлечь клиентов), `sales` (посчитать и продать), `ops` (наладить работу), `showcase` (показать себя).
- `image` — обложка 1440×900 в WebP. Если пусто, показывается цветная плашка цвета `color` с надписью `watermark`; для светлой плашки добавьте `"light": true`.
- `url` пустой — вместо кнопки «Открыть вживую» будет «Скоро онлайн».
- `extra` внутри `ru` / `en` — необязательная вторая кнопка, например ссылка на PDF: `"extra": { "label": "Чек-лист PDF", "href": "https://…" }`.

## Запуск и сборка

```bash
npm ci
npm run dev      # http://localhost:5173, обновляется при сохранении
npm run build    # готовый сайт в dist/
```

Нужен Node.js 18 или новее (Vite 5).

## Форма заявки

Форма отправляет `POST` на адрес из `site.json` → `leadApi` (сейчас `https://leads.myfreelab.ru/api/lead.php`) с типом `text/plain`. Перед отправкой обязательна галочка согласия со ссылкой на `privacy.html`, от ботов стоит скрытое поле-ловушка `website`. Сам приёмник заявок — отдельный проект, в этом репозитории его нет.

## Публикация

Сайт статический: содержимое `dist/` копируется в `/var/www/myfreelab.ru` на сервере (Nginx, раздача SPA, HTTPS от Let's Encrypt).

```bash
npm run build
rsync -a --delete dist/ <пользователь>@<сервер>:/var/www/myfreelab.ru/
```

С Windows то же самое делает `deploy/deploy.ps1`. Настройки кэша и сжатия для Nginx — `deploy/myfreelab-static.conf`, инструкция в начале файла.

Перед заменой рабочей версии сохраните копию: `tar czf ~/backups/myfreelab.ru-<дата>.tar.gz -C /var/www myfreelab.ru`.

## Что ещё лежит в репозитории

- `ops/` — служебные скрипты: публикация кейсов на поддоменах и в GitHub, тесты форм кейсов, Apps Script для заявок, заполнение учебных тетрадей. Для работы витрины не нужны.
- `AUDIT-2026-10-29.md` — разбор витрины глазами посетителя, с которого началась версия «Лаборатория».
